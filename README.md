# Business Hunter

Private mobile-first web app for collecting and comparing businesses for sale.

## V1
- Add/edit listings
- Search/filter/sort
- Asking price, turnover, stated profit and profit measure
- Price/profit multiple
- Growth opportunity and risk notes
- Simple assessment score
- Status pipeline
- Export/import backup
- Installable PWA
- LocalStorage only

## Next build step
Add a server-side listing collector and shared database so listings can be found automatically and synced across devices.
